# shared/OpenApi — Published REST contracts

Machine-generated OpenAPI documents, one per REST host — the single place
desktop/GUI clients pick API specs from for their client implementations.
Regenerated on every build of the owning project; **do not edit by hand**.

| File | API | Regenerated by |
|---|---|---|
| `Server.json` | Strategist Server API (GUI REST surface) | Server build |
| `fleet-v1.json` | Fleet Control Plane (fleetd `/api/v1`: terminal lifecycle + provisioning, templates, VNC) | `dotnet build Fleet.csproj` in the [Fleet](https://github.com/ultimatesoftwares/Fleet) repo (build-time OpenAPI generation) |
