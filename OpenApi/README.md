# shared/OpenApi — Published REST contracts

Machine-generated OpenAPI documents — the single place desktop/GUI clients
pick API specs from for their client implementations. **One subdirectory
per service**, so each service regenerates its own documents on every build
without touching anyone else's. **Do not edit by hand.**

| Path | API | Regenerated by |
|---|---|---|
| `Server/server-v1.json` | Strategist Server API (auth/identity: token, register, profile, users, roles + the strategy-project pipeline, the research plane: backtests/history/instruments, and the MetaTrader terminal fleet: terminals/image) | `dotnet build Server.csproj` in the [strategist_server](https://github.com/ultimatesoftwares/strategist_server) repo (build-time OpenAPI generation) |
| `Bot/bot-v1.json` | strategist_bot control API (:5080 — venues, accounts/positions/orders, risk, instrument registry + catalogs, history, MT terminals) | `dotnet build src/Bot` in the [strategist_bot](https://github.com/ultimatesoftwares/strategist_bot) repo (build-time OpenAPI generation) |

Both documents are OpenAPI **3.1** (unsupported by progenitor), so the
desktop transcribes its typed Rust clients by hand from these documents and
the controllers (see `strategist_desktop/crates/protocol`).

Auth: every server operation requires `Authorization: Bearer <access token>`
(ES256 JWT from `POST /api/v1/token`); the bot plane is unauthenticated
(private network, fronted by Caddy in production).
